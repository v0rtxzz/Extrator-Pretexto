# Provas (PDFs)

Coloque aqui os PDFs oficiais, na convenção:

```
provas/ANO/CATEGORIA/dia1-prova.pdf    dia1-gabarito.pdf
provas/ANO/CATEGORIA/dia2-prova.pdf    dia2-gabarito.pdf
```

Categorias: `regular`, `ppl`, `digital`, `segunda`, `terceira`. Exemplo: `provas/2025/regular/dia1-prova.pdf`.

Os PDFs não vêm neste zip (são grandes). Para 2024 e 2025, use os mesmos que já estão no seu projeto.
Veja `docs/USO-EXTRATOR.md`.
